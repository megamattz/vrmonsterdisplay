VR Monster Display

This is a simple threejs app to show off the model I made and be able to view it in VR via the web. 

References Used

This model is loosly based on the one from the Blendermania Udemy Course 'The Ultimate Blender 3D Sculpting Course' by Alex Cordebard. although I did modify it quite a bit from the one created on the course.  

It makes use of some of the base textures provided in that course.
